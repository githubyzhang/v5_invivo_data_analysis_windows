## Recording boundary and Round 2 follow-up

The original boundary screen contains five events: clusters 34/36/37/58 at sample 2 and 39 at sample 3. All lack a complete nominal 61-sample template support around the event. Coincidence across distinct locations plus missing pre-recording support warrants a boundary warning; it does not prove every event is artificial. Clusters 36/39 were included only as boundary context, not fully reviewed in this round.

The [recording-start plot](../../results/extra4_shank0/pilot01-round1/boundary_context.png) shows b248/global1921 flat at zero. An explicit prefix scan found samples `[0,2171)` exactly equal to zero, with the first change at sample 2171 (217.1 nominal ms). Cluster 36's whitened-template peak is b248; whitening/CAR can mix channel information, so that fact is not an event-level diagnosis. Add this prefix to Round 2 alongside the known later flat/disturbance windows; no automatic mask is adopted.

Round 2 retains pairs 31/33 and 45/48, channel 248 and disturbance windows. This round additionally motivates isolation checks for 5/6, 2 versus 0/1/3, 26/27, and cluster 35's feature structure. These are diagnostic comparison priorities, not merge or split instructions.

## Scope and limitations

Raw review used 256 evenly spaced event ranks for each of 34/35/5/12/2, all 59/34 events for 26/29, and no padded windows for 37/58: 1,373 complete windows total. Each window spans offsets -100 through +100 samples. Displays multiply unchanged source values by 1e6 and subtract the median over offsets -100 through -31 per event/channel. No filtering, CAR, interpolation or resampling was applied to these raw windows. Numerical scaling does not establish voltage calibration. Three individual snippets per complete-window cluster were visually inspected in addition to its averages, feature plots and time summaries; this is not exhaustive inspection of all events.

Quarter correlations compare a quarter mean with an all-selected mean containing that quarter, so they are descriptive, not independent validation. All-event amplitude summaries and rates use the complete recording. Nominal fs=10,000 Hz, physical fs=10,080 Hz; exposure is 300 nominal/297.619048 physical seconds. ACGs use 1 nominal ms bins; ISI counts use <10/<20 integer samples. Two-sample sorter duplicate suppression limits the shortest intervals; low event counts additionally limit sparse-cluster conclusions.

PC1/2 comparisons use the same physical binary channel across clusters, map through each cluster's stored pc_feature_ind, and screen neighbors by template peak within 60 µm. This is a restricted two-dimensional projection, not an isolation-distance score or complete neighboring population. Missing channels/comparators are explicitly recorded.

All 18 per-cluster figures and the boundary context figure were visually reviewed. Independent checks reproduced every saved raw-window value directly from the binary and verified selection indices, key original metrics and labels. The raw SHA-256 matches before/after, and all 169 frozen-return payloads remain unchanged. The three new algorithm tests pass. No sorter or saved-preprocessing reconstruction was run; the current FAISS repair did not change the original pilot's provenance.
